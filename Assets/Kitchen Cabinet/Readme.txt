Soviet Kitchenware Pack - Kitchen Cabinet Documentation

General Information:
-------------------
Thank you for purchasing this asset! 
This package contains a modular, game-ready Soviet-style kitchen cabinet model with separate drawers, optimized for real-time engines.

Technical Specifications:
-------------------------
- Package Name: SM_Kitchen_Cabinet
- Included Meshes:
  * SM_Kitchen_Cabinet_Base (Main frame)
  * SM_KitchenCabinet_Drawer_01 (Top drawer)
  * SM_KitchenCabinet_Drawer_02 (Middle drawer)
  * SM_KitchenCabinet_Drawer_03 (Bottom drawer)
- Total Triangles: 684
- Total Vertices: 358
- Material Name: M_Cupboard_Base
- Textures: Included PBR textures (Albedo, Normal, Metallic/Roughness)
- UV Mapping: Yes, fully unwrapped, non-overlapping UVs

Setup Instructions:
-------------------
1. Open the project in Unity.
2. Navigate to the "Prefabs" folder.
3. Drag and drop the "SM_Kitchen_Cabinet" prefab into your scene.
4. Drawers are separated and properly aligned, allowing you to easily animate or move them.
5. The prefab is already configured with materials and correct pivot points.
