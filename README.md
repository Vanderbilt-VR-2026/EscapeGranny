## Greybox house

1. Open a scene in Unity.
2. **Tools → Escape Granny → Build House**. The house appears as `House (generated)`.
3. Hide the **Roof** object to see inside.
4. Move **XR Origin** to `(7.5, 0, 6.5)` to start in the ground hallway.

- Running Build House again replaces the old house. **Tools → Escape Granny → Remove House** deletes it. 
- Layout numbers are at the top of `Assets/Editor/HouseBuilder.cs` and match `floor_plan.pdf`.
